# Meu Fluxo

App pessoal de controle de pagamentos quinzenais — feito para abrir rápido no celular e no notebook, com os dados sincronizados pelo próprio GitHub (sem precisar de servidor).

## Como usar

1. Abra o app publicado no GitHub Pages.
2. Nas **Configurações** (ícone de engrenagem), cole um token de acesso pessoal do GitHub para habilitar a sincronização entre aparelhos (o passo a passo de como gerar o token está lá dentro).
3. Marque contas como pagas, adicione novas contas, acompanhe parcelas e abra as próximas quinzenas conforme for precisando.

Os dados ficam guardados em `data.json`, neste mesmo repositório.
