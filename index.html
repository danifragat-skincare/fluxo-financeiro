        Como gerar o token

        1. Acesse github.com/settings/personal-access-tokens/new
        2. Em "Repository access", escolha Only select repositories e selecione
        3. Em "Permissions → Repository permissions", ache Contents e mude para Read and write
        4. Clique em Generate token e copie o código gerado
        5. Cole aqui nas Configurações, em "Token de acesso pessoal"

        Esse token fica salvo só neste aparelho. Repita em cada aparelho (celular e notebook) que for usar.
